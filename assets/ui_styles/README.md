# Style previews

`preview_<style>.png` are real screenshots of the Office in each UI style (living_office, broadcast, woodblock), cropped and shrunk, shown on the Marketplace's Office styles tab. Retake them when a style's Office changes: run the Office in that style at 1080 x 2340, crop the name plate or pins (top) and the docket card and tiles (bottom), scale to 420 px wide.
