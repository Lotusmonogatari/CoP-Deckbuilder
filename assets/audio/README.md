# Sound files

Empty on purpose. Drop `.ogg` files in here and name them in
`data/sounds.json` against the moment they belong to — `card_played`,
`gaffe_final`, `battle_won` and the rest. Nothing in any script needs to
change.

Until then the game is silent: a blank filename is a no-op, and a filename
pointing at a file that is not here logs one line and is ignored.

`.ogg` is the safe choice on both phones. Keep effects short and quiet
enough to sit under speech.
