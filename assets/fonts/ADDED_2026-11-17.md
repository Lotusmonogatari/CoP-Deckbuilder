# Fonts added for the UI styles (P9, 2026-11-17)

All three families are licensed under the SIL Open Font License 1.1 (the same licence text as `OFL.txt` in this folder). They were fetched from Google Fonts. Only the Latin subset of each is included; Japanese text falls back to Noto Sans JP, as it does for Antaka.

| File | Family | Used by |
|---|---|---|
| BarlowCondensed-BoldItalic.woff2 | Barlow Condensed, bold italic | Broadcast (display) |
| ShipporiMinchoB1-Regular.woff2, -Bold.woff2 | Shippori Mincho B1 | Woodblock (body) |
| ZenKakuGothicNew-Regular.woff2, -Bold.woff2 | Zen Kaku Gothic New | Living Office (body) |

## Added 2026-11-21: accented letters

| File | Family | Used by |
|---|---|---|
| BarlowCondensed-BoldItalic-LatinExt.woff2 | Barlow Condensed, bold italic, Latin-extended piece (ā ī Ō ō ū Ū and more) | Broadcast (display): the first fallback behind Barlow |

Shippori Mincho B1 and Zen Kaku Gothic New have **no** macron letters at all (their Latin-extended pieces hold ten and twenty-three glyphs and none of ā ī ō ū), so no piece was added for them. Their accented letters come from **Antaka Brush Text**, which has them (ō Ō ū Ū ā ī é ü ñ), set as the first fallback behind each body face (`UiStyleTheme.ACCENT_FALLBACK`), with Noto Sans JP last for Japanese and −, ×, →. Antaka Brush Display and Text are unchanged wherever they are used.
